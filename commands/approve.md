# /design-kit:approve

**Mô tả:** Hoàn thiện project và sinh toàn bộ tài liệu thiết kế chi tiết (7 documents). Dùng khi spec đã ổn định và sẵn sàng chuyển sang giai đoạn production.

## Steps

1. Show current project assets before approval:
   - Already generated from `/design-kit:concept` Phase B:
     - `{project}/gcd.md`
     - `{project}/gcd-gameplay.md`
     - `{project}/spec.yaml`
   - Additional docs to be generated by `/design-kit:approve` under `{project}/documents/`
2. Show a concise spec summary:
    - Title
    - Version
    - Iteration count
    - Pillars
    - Core mechanics
3. Ask for final confirmation to approve.
4. Generate 7 additional detail documents under `{project}/documents/`:
    - `gameplay-design.md`
    - `ui-ux-spec.md`
    - `economy-design.md`
    - `art-direction.md`
    - `content-plan.md`
    - `technical-requirements.md`
    - `sound-design.md`
5. For each additional document:
    - Search knowledge base for relevant best practices
    - Expand corresponding spec sections into implementable detail
6. Show completion summary with all file paths (existing + newly generated).

## Output Requirements

- Keep documents actionable for production teams.
- Cross-reference specs and related documents.
- Cite source and page when design guidance is theory-dependent.
