📋 01 · Tổng quan

Một bộ kit, cả pipeline thiết kế game

Game Design Kit là Claude Code plugin orchestrate một pipeline AI hoàn chỉnh — từ ý tưởng thô đến tài liệu thiết kế chi tiết. 11 agents được tổ chức 3 tầng (Director → Producers → Reviewers), mỗi tầng có vai trò rõ ràng, tự động review chéo, và bắt buộc người dùng approve trước khi sang bước kế tiếp. Toàn bộ kit là file markdown được Claude Code đọc runtime — không cần build, không Docker, không CI/CD.

🏛 02 · Kiến trúc 3 tầng

Director điều phối · Producer sản xuất · Reviewer kiểm chất lượng

Mỗi tầng có một mission tách biệt. creative-director (T1) giữ vision và quyết định gate; T2 producers tạo artifacts; T3 reviewers tự động được trigger ngay sau khi T2 hoàn thành.

T1 Director creative-director
Điều phối toàn bộ pipeline · Holds vision & pillars · Quyết định approval gate · Delegate cho Producers, ủy thác Reviewers.
T2 Producers 1 skill + 4 agents tạo artifacts
Skill game-prototype sở hữu toàn bộ early pipeline (concept brainstorm → playable HTML5 → lightweight Vietnamese GCD). 4 producer agents tiêu thụ output đã approve để sinh mockup, wireframe, detail docs. Output co convention nghiêm ngặt (file path, format, ngôn ngữ).

Phase 1 brainstorm + audit · Phase 2 [slug]-vN.html · Phase 3 lightweight GCD (vi)

wireframe-designer

T3 Reviewers 3 agents auto-review (+ 1 legacy)
Tự động trigger ngay sau Producer hoàn thành. Review theo criteria có sẵn trong references/, cho điểm và yêu cầu fix nếu fail.

🛠 03 · Pipeline thiết kế

7 bước · 4 approval gates · zero auto-advance

Lệnh /design-kit:create <ý tưởng> kích hoạt toàn bộ pipeline. Skill game-prototype chạy end-to-end Phase 1+2+3 để chốt playable prototype + lightweight GCD; sau đó mockup → wireframe → detail docs tiêu thụ output đã approve. Mỗi artifact được approve thủ công trước khi sang bước kế. Không có bước nào auto-advance.

00

Setup project + (optional) market research

Tạo thư mục projects/{project-name}/Game Demo/. Nếu user muốn, khởi market-researcher chạy background để feed insights vào Phase 1 của skill.
projects/{name}/Game Demo/ market-researcher (optional)
01

game-prototype skill · Phase 1 · Brainstorm + Audit (Gate 1)

Skill thu thập Target Audience + Problem Statement + 8 Kinds of Fun, suggest 3 gameplay options, sinh 3 mini concept prototypes Game Demo/[slug]-concept-{A|B|C}.html (~300-500 dòng), chạy Pre-Prototype Audit (5 layers) và Anti-pattern Audit, user chốt 1 option ± remix.
game-prototype (skill) Game Demo/[slug]-concept-{A|B|C}.html Gate 1
⬇ Approval Gate · Gate 1
02

game-prototype skill · Phase 2 · Versioned Playable Prototype (Gate 2)

Skill expand option đã chốt thành full playable HTML5 Game Demo/[slug]-v1.html (vanilla JS + Canvas, hoặc Three.js CDN nếu 3D), self-test theo template, iterate với user. Mỗi revision sinh -v2.html, -v3.html, ... không overwrite bản cũ.
game-prototype (skill) Game Demo/[slug]-vN.html Gate 2
⬇ Approval Gate · Gate 2
03

game-prototype skill · Phase 3 · Lightweight GCD (tiếng Việt)

Skill xuất Game Demo/[slug]-GCD.md bằng tiếng Việt, derive 1:1 từ [slug]-vN.html final ± Phase 1 context. KHÔNG tự tạo cơ chế mới không có trong prototype.
game-prototype (skill) Game Demo/[slug]-GCD.md (vi)
⬇ Approval Gate
04

High-fi Mockup

Mockup tất cả screens · mobile viewport 390×844 · sidebar nav · embedded dom-grab component picker (CDN). Mỗi component có data-component attribute.
mockup-designer mockup.html ui-ux-reviewer
⬇ Approval Gate
05

Wireframe Overview

Single-page flowchart mọi screens · SVG wires navigation · click-to-expand component spec panel. Bắt buộc 1:1 sync với mockup.
wireframe-designer wireframe.html ui-ux-reviewer
⬇ Approval Gate · Feedback Window
06

Feedback Gate

feedback-interpreter nhận feedback từ user, structure thành change plan với diff preview. KHÔNG auto-apply.
feedback-interpreter diff preview
07

Detail Design Documents

User chọn loại tài liệu cần generate (UI/UX spec, art direction, gameplay spec, market research...). Mỗi doc auto-review bởi reviewer phù hợp.
document-writer market-researcher detail-doc-reviewer
⚙️ 04 · Công nghệ

Markdown-first · Zero build · MCP-powered

Toàn bộ kit là files markdown được Claude Code interpret runtime. Tri thức game design chảy qua Hindsight MCP. Artifacts sinh ra dùng vanilla JS, không framework.

Markdown-defined agents

Mỗi agent là file .md với YAML frontmatter (name, description, model, color, tools) + behavioral instructions. Claude Code đọc & thi hành runtime.

no compileplugin runtime

Claude Code Plugin Framework

Plugin identity ở .claude-plugin/plugin.json. Permissions trong settings.json. SessionStart hook ở hooks/hooks.json. Tích hợp commands + agents + skills.

plugin.jsonmarketplace

Hindsight MCP

HTTP MCP server tại hindsight.zingplay.dev. Cung cấp tri thức game design qua tools recall, reflect, list_banks; external knowledge writes are staged through a governance gate before retain.

game-knowledge bankBearer auth

dom-grab

Component picker library load qua CDN trong mockup. Đọc attribute data-component trên từng component để cho user click chỉ thẳng vào element và feedback context-rich.

CDNmockup-only

Vanilla JS + Canvas + SVG

Prototype, mockup, wireframe đều dùng vanilla JS — không framework. Canvas API cho 2D, Three.js qua CDN nếu cần 3D. Wireframe dùng inline SVG cho flowchart.

no React/Vueno build

Zero build step

Không Docker, không CI/CD, không bundler. Plugin files = runtime artifacts. Đường dẫn resolve qua biến ${CLAUDE_PLUGIN_ROOT}.

plugin = file$CLAUDE_PLUGIN_ROOT

🧠 06 · Hệ thống tri thức

Tri thức game design qua Hindsight MCP

Agents không chứa tri thức cứng — mọi thứ chảy qua Hindsight MCP, một remote HTTP server. Khi agent cần ground recommendation theo theory, nó gọi recall/reflect; khi học được điều mới, nó stage pending contribution để reviewer/user approve trước khi external retain.

🪪 Auth

Bearer token
Yêu cầu env var HINDSIGHT_API_KEY. SessionStart hook cảnh báo nếu thiếu.

🏦 Bank

game-knowledge
Bank tri thức chuyên về game design theory, mechanics, patterns.

🛠 Tools

recall · reflect · list_banks · gated retain
Set tool MCP đầy đủ trong settings.json allow-list.

🌐 Endpoint

hindsight.zingplay.dev
/mcp/game-knowledge/ · HTTP transport · centralized.
🚀 07 · Cách hoạt động

4 bước để chạy đầy đủ pipeline

Cài plugin → set API key → chạy command → approve từng artifact. Toàn bộ pipeline được điều phối tự động.

01

Cài plugin

Cài Game Design Kit qua Claude Code marketplace hoặc git clone vào ~/.claude/plugins/.

install.sh
02

Set API key

Export biến môi trường để Hindsight MCP có thể auth thành công.

export HINDSIGHT_API_KEY=...
03

Chạy create

Khởi động pipeline với 1 idea bất kỳ — kit sẽ guide đến tất cả các bước.

/design-kit:create <ý tưởng>
04

Approve theo gate

Mỗi bước producer xong sẽ chờ approve. Có thể dùng /design-kit:iterate để feedback.

Approve · Request changes · Skip
⌨️ 08 · Slash Commands

4 lệnh điều khiển toàn bộ kit

Mỗi command là file markdown trong commands/ với YAML frontmatter (description, argument-hint) + numbered steps. User-facing entry points của kit.

/design-kit:create <idea>
Pipeline đầy đủ 11 bước từ idea đến detail docs. Có approval gate sau mỗi producer step.
/design-kit:iterate <feedback>
Cập nhật artifact theo feedback. feedback-interpreter propose change set, hiện diff preview, chỉ apply khi user approve.
/design-kit:status
Báo trạng thái pipeline hiện tại: artifacts đã có / thiếu, stage đang ở đâu, Hindsight MCP stats.
/design-kit:setup [update|doctor]
Kiểm tra version plugin, update từ GitHub releases, chạy diagnostic. Subcommands: update, doctor.
🛡 09 · Nguyên tắc pipeline

Nguyên tắc bất di bất dịch

Pipeline được thiết kế để fail informatively. Approval gate ngăn downstream damage; auto-reject các pattern sai từ early stage.

✅
Approval gate sau mọi producer step Không bước nào auto-advance. User phải explicit approve hoặc request changes.
✅
Diff preview trước khi apply feedback Mọi thay đổi từ iterate đều show diff trước. User approve mới apply.
✅
Mockup BẮT BUỘC có dom-grab picker Mỗi component có data-component attribute để user click feedback chính xác.
✅
Wireframe BẮT BUỘC 1:1 với mockup Không invent screens / components không có trong mockup.html.
🚫
Không framework deps trong prototype/mockup/wireframe Chỉ vanilla JS + Canvas + inline SVG. dom-grab via CDN OK trong mockup.
🚫
Không overwrite playable prototype cũ Mỗi iteration phải sinh Game Demo/[slug]-vN+1.html, không ghi đè. Lightweight GCD phải 1:1 với prototype.
🚫
Không auto-apply feedback changes Luôn show diff preview trước. Mockup không picker → auto-REJECT.
🚫
Không hard-code paths Mọi đường dẫn dùng env var ${CLAUDE_PLUGIN_ROOT}.
