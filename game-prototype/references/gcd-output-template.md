# GCD Output Template (Lightweight)

Knowledge base cho skill `game-concept-automatic`. Sử dụng ở Phase 3 (xuất GCD nhẹ sau khi prototype được chốt).

## Triết lý

GCD nhẹ này KHÁC với output của skill `game-concept-design`:
- KHÔNG include 12 lý thuyết game design (MDA, Flow, Risk/Reward...)
- KHÔNG include phân tích sâu về Aesthetics / Mechanics / Dynamics
- CHỈ document những gì **đã prototype hóa** trong file HTML

Đây là **artifact đi kèm prototype**, không phải GDD đầy đủ.

## Quy trình generate

1. Đọc file HTML đã chốt (final version)
2. Đọc lại conversation history Phase 1 + Phase 2
3. Fill template dưới đây với data thực tế (không bịa)
4. Save vào `Game Demo/[slug]-GCD.md`


## Quy tắc generate

### MUST DO

- ✅ Section 3 (Screens) phải khớp 1-1 với screens trong HTML (cùng số lượng, cùng tên)
- ✅ Section 4.2 (Resolve rules) phải đọc thực tế từ JS code, không bịa formula
- ✅ Section 4.3 (Random) phải scan `Math.random()` trong code
- ✅ Section 5 version history phải reference conversation thực tế (đổi gì ở mỗi version)

### MUST NOT

- ❌ Include 12 lý thuyết game design (MDA, Flow, Decision Theory, etc.)
- ❌ Phân tích Aesthetics depth, Player Motivation Strategy
- ❌ Đề xuất feature mới chưa có trong prototype
- ❌ Bịa rule không có trong HTML
- ❌ Copy paste từ template này — phải fill data thực
